 Furniture Store Project
Kani waa mashruuc degel internet (website) oo loogu talagalay dukaanka alaabta guriga (Furniture Store). Waxaa loo dhisay si casri ah, isagoo si buuxda ugu shaqaynaya aaladaha kala duwan sida Desktop, Tablet, iyo Mobile (Full Responsive Design).

 Tilmaamaha Mashruuca (Features)
Navigation Bar Casri ah: Waxay leedahay menu isku laabmaya (Hamburger Menu) marka la joogo mobile-ka.

Hero Section: Qayb soo jiidasho leh oo leh sawir weyn iyo qoraal dhiirigelin ah.

Product Display: Qayb lagu soo bandhigo alaabta kala duwan (Imported & Local), iyadoo magacyada iyo qiimuhu ay dhexda ku yaallaan (Centered).

About Us: Qayb ka sheekaynaysa tayada iyo adeegga dukaanka.

Services: Liiska adeegyada uu dukaanku bixiyo sida Delivery-ga bilaashka ah.

Contact Form: Foom ay macaamiishu ku soo diri karaan fariimaha.

Fully Responsive: Waxaa loo habeeyay inuu si qurux badan ugu soo baxo shaashad kasta iyadoo la isticmaalayo CSS Media Queries.

🛠️ Tiknoolajiyadda la isticmaalay (Technologies)
HTML5: Qaabdhismeedka bogga.

CSS: Qurxinta iyo habaynta (Grid, Flexbox, iyo Animations).

JavaScript: Shaqada Hamburger Menu-ga (Open/Close functionality).

Font Awesome: Icons-ka loo isticmaalay menu-ga iyo qaybaha kale.

Google Fonts: Font-ka 'Nunito' iyo 'Muli' oo loo isticmaalay qoraalka.

 Qaabdhismeedka Faylasha (File Structure)
index.html: Faylka ugu weyn ee ka kooban nuxurka website-ka.

style.css: Faylka ka kooban dhamaan CSS-ka iyo nashqadda.

README.md: Warbixinta mashruuca (Faylkan hadda aad akhrinayso).
